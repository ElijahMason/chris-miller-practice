Fourth letter

Staying in the room

Dear reader,

An on-site working session is how a long problem gets a page. I travel. I sit with the people who hold the constraint. A long trip is acceptable when the problem is in the room.

When the page is honest, I build the software it describes. If the room changes a decision, the spec changes in writing, and then the system moves.

At the end I walk the system with you. You keep the system and the spec. The next person can see what was refused.

Yours,

Chris Miller
