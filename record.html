What I write down

Dear reader,

The spec is not a diary. A line is a decision the room agreed to, a refusal the room made, an open point with a name beside it, or the next step and who takes it.

A refusal is as useful as a decision. If it is not written, the build wanders back to it. I write while the talk is still in the room, so the sentences stay yours.

Yours,

Chris Miller
